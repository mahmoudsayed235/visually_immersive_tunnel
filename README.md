#  Visually Immersive Tunnel

A futuristic, immersive tunnel experience built in **Unity 3D**, featuring LED-style animated screens, ambient particle effects, and dynamic lighting. Inspired by sci-fi aesthetics, this project simulates walking through a digital corridor using a combination of shaders, VFX, and post-processing.

---

##  Features

###  Tunnel Setup
- 3-screen tunnel layout: **Left**, **Right**, and **Bottom** panels
- Futuristic design with **emissive materials** and glowing edges

###  LED Screens
- **Left & Right Screens**:
  - Display a scrolling welcome message: `"Welcome to Armco"`
  - **Bottom Screen**:
  - Animated digital patterns using Shader Graph for a sci-fi effect

###  Particle System
- Floating, glowing particles to enhance the environment
- Customizable color, speed, and emission settings
- Spark and energy trail effects for added immersion

###  Visual Effects
- **Post-processing** via URP:
  - Bloom for emissive glow
  - Color grading for a sci-fi color palette
- **Volumetric lighting** to simulate atmospheric depth

###  Player Movement
- **Mouse and Keyboard input** support:
  - WASD / Arrow keys for movement
  - Mouse look for camera control (Click on Left button)
- Smooth movement and camera follow system
